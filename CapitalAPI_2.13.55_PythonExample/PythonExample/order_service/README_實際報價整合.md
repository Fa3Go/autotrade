# 雙賣價差單策略 - 實際報價整合說明

## 功能概述

雙賣價差單策略現在支援在測試模式中抓取實際的期貨報價，讓您可以在不實際下單的情況下，使用真實的市場價格來測試策略邏輯。

## 新增功能

### 1. 實際報價整合
- **自動偵測報價模組**：系統會自動檢查Quote模組是否可用
- **即時價格抓取**：可以抓取期貨的實際即時價格
- **價格快取機制**：避免頻繁查詢，提升效能

### 2. 測試模式增強
- **模擬價格**：手動設定價格進行測試
- **實際報價**：在測試模式中使用真實市場價格
- **混合模式**：可以在實際價格基礎上進行調整測試

### 3. 用戶界面
- **報價狀態顯示**：顯示報價連線狀態和最新價格
- **抓取實際價格按鈕**：手動更新當前市場價格
- **實際報價開關**：控制是否使用實際報價

## 使用方法

### 步驟1：啟動報價連線
1. 在主程式中切換到「報價」tab
2. 點擊「報價連線」按鈕
3. 確認連線成功後，訂閱您要監控的期貨商品

### 步驟2：配置雙賣策略
1. 切換到「雙賣價差單策略」tab
2. 在測試模式設定區域：
   - ☑️ 啟用測試模式（不實際下單）
   - ☑️ 使用實際報價（需先連線報價系統）

### 步驟3：抓取實際價格
1. 點擊「抓取實際價格」按鈕
2. 系統會自動獲取當前期貨價格
3. 價格會顯示在模擬價格欄位中

### 步驟4：測試策略
1. 設定好策略參數
2. 點擊「計算價差策略」查看分析
3. 點擊「開始監控」進行即時監控測試

## 價格來源模式

### 純模擬模式
- 使用手動設定的模擬價格
- 適合測試特定價格情境
- 可用±100按鈕快速調整價格

### 實際報價模式
- 從報價系統抓取真實價格
- 價格會自動更新到模擬價格欄位
- 適合測試真實市場情況

### 混合模式
- 在實際價格基礎上手動調整
- 可以模擬價格突破情境
- 結合真實與模擬的優點

## 注意事項

### 報價系統要求
1. **報價連線**：必須先在報價tab建立連線
2. **商品訂閱**：需要訂閱要監控的期貨商品
3. **網路穩定**：確保網路連線穩定以獲取即時價格

### 價格更新機制
1. **快取時間**：價格快取30秒，避免過於頻繁查詢
2. **自動更新**：監控過程中會自動更新價格
3. **錯誤處理**：無法取得實際價格時會fallback到模擬價格

### 測試建議
1. **先測試連線**：確認報價系統正常運作
2. **驗證價格**：比對抓取的價格是否合理
3. **測試避險**：使用價格調整按鈕測試避險觸發條件

## 技術實作

### 價格抓取流程
```
1. 檢查報價模組可用性
2. 從快取中查找最新價格
3. 如快取過期，呼叫報價API
4. 更新快取和UI顯示
5. 返回價格供策略使用
```

### 錯誤處理
- **模組不可用**：顯示警告訊息，僅能使用模擬價格
- **連線失敗**：fallback到模擬價格，記錄錯誤訊息
- **API呼叫失敗**：使用快取價格或模擬價格

### 效能最佳化
- **價格快取**：避免重複查詢相同商品
- **非同步更新**：不阻塞UI操作
- **錯誤恢復**：自動重試和降級處理

## 故障排除

### 無法抓取實際價格
1. 檢查報價系統是否已連線
2. 確認商品代號是否正確
3. 檢查網路連線狀況
4. 查看系統日誌訊息

### 價格更新不即時
1. 檢查快取設定（30秒更新間隔）
2. 確認監控是否正在運行
3. 手動點擊「抓取實際價格」更新

### 報價模組載入失敗
1. 檢查Quote_Service目錄是否存在
2. 確認SKCOM.dll等檔案是否完整
3. 查看程式啟動時的錯誤訊息
